## Current personal project

**Governed AI-agent ERP automation** in an isolated lab, synthetic data only.

- **Controls:** a kill switch, an independent verifier, and a person still holding the approval gates.
- **Verification:** a deterministic, independent verifier scores results against the database. The agent does not grade itself.
- **Lab result:** in later lab rounds, the verifier recorded 59 of 64 standard jobs as passes (92%).
- **Status:** personal research in an isolated lab with synthetic data. Not a live public demo and not a client deployment.
